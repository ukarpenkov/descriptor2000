# Descriptor2000

Локальная расшифровка аудио и видео в настольном приложении. TypeScript, React, Electron, Elysia и Transformers.js. Без облачной обработки записей.

## Запуск разработки

Node.js 24, npm, macOS или Windows:

```sh
npm ci
npm run dev
```

Откроется одно окно приложения. Выберите или перетащите файл, укажите язык и модель, нажмите «Расшифровать». Первое использование скачивает ONNX-модель Whisper с Hugging Face. Отдельная кнопка позволяет скачать модель заранее. После скачивания модель кэшируется в каталоге `models` внутри Electron `userData`.

```sh
npm test
npm run build
npm run dist -- --publish never
```

`release/` содержит установщик: DMG на macOS, NSIS EXE на Windows. После установки запуск обычной иконкой. Собирать под соответствующей ОС; `.github/workflows/build.yml` запускает обе платформы. Текущие сборки не подписаны; публичные установщики потребуют сертификатов Apple/Microsoft.

## Реализовано в 0.1

- Whisper Tiny, Base, Small, CPU, квантование q8, загрузка и повторное использование моделей.
- MP4, MP3, M4A, WAV, AAC, AMR, 3GP, OGG, OPUS, FLAC, MOV, MKV, WEBM, CAF, AIFF, WMA через комплектный FFmpeg. Конкретная поддержка зависит от кодека; зашифрованные файлы не поддерживаются.
- Русский, английский, испанский, французский, немецкий и определение языка.
- Расшифровка на исходном языке; опциональный перевод речи на английский средствами Whisper.
- Указание 1–12 говорящих и ручное назначение говорящего каждому фрагменту. Автоматической диаризации пока нет.
- Процент распознавания по обработанной длительности, прогресс загрузки текущего файла модели, неопределённый индикатор извлечения аудио. Отмена между этапами/фрагментами; текущая операция ONNX может завершиться перед отменой.
- Редактирование, копирование результата, сохранение TXT, чёрная и белая темы.

## Архитектура

`electron/main.ts` управляет окном, файловыми диалогами и очередью из одной операции. Изолированный preload предоставляет ограниченный IPC. `electron/service.ts` содержит Elysia API с валидацией параметров. Вызовы маршрутизируются через `app.handle(Request)` внутри процесса: TCP-порт не открывается. `electron/worker.ts` запускает FFmpeg и локальный ONNX inference вне UI-потока. Renderer не имеет доступа к Node.js.

FFmpeg извлекает моно PCM 16 kHz во временный каталог; worker читает фрагменты по 25 секунд. Оперативная память для аудио ограничена размером фрагмента, временный диск должен вмещать около 230 MB на час записи. Фрагменты независимы, поэтому слова на границах могут теряться и контекст между фрагментами не сохраняется. Временные файлы удаляются в `finally` при обычном завершении или отмене; после аварийного завершения ОС временный каталог может остаться.
